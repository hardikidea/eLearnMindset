# Drona Learning Cloud HTML Showcase

Open `public-home.html` first. It is the public, no-login LMS showcase with an animated hero, platform preview, programme cards, role-experience slider, bento features, community showcase, events, calls to action and a standard institutional LMS footer.

Use `role-login.html` to review role-specific authentication experiences. Use `all-pages.html` to browse the full 54-page prototype.

## Design system
- Modern glass and layered surface system
- Responsive flex/grid layouts from 320px through wide desktop
- Teacher red, student blue, administrator green, parent purple and participant orange
- CSS/JavaScript motion with `prefers-reduced-motion` support
- Local assets only; no CDN dependency
- Shared mini-footer automatically added to authenticated application layouts

## Repository implementation
Read `CODEX_IMPLEMENTATION_PROMPT.md` before asking Codex to convert this visual reference into a Moodle 5.0.2 theme. The HTML is a visual prototype, not a replacement for Moodle templates or APIs.
