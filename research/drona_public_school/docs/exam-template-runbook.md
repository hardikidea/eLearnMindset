# Exam Template Runbook

Every grade has term exam templates and final exam templates.

Files:

```text
templates/exams/term_exam_templates.csv
templates/exams/term_exam_activities.csv
templates/exams/final_exam_templates.csv
templates/exams/final_exam_activities.csv
```

Every course has generated rows in:

```text
years/<year>/course_term_exams.csv
years/<year>/course_final_exams.csv
```
