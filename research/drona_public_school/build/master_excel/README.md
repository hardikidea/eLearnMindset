# Master Excel Notes

`drona_public_school_2026_2027_sample_master.xlsx` is a capped review workbook generated from the validated 2026-2027 assembled CSV files.

The full local-testing dataset is intentionally kept in CSV form because it contains thousands of rows:

- 5,220 students
- 4,698 parents
- 2,160 groups per academic year
- 2,160 enrolment mappings per academic year

Use the workbook to review structure, headers and examples. Use `build/assembled_csv/<academic-year>/` for real Moodle validation and import.
